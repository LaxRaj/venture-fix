7. THE MODEL LAYER: GOOD NEWS IS DISCARDED, BAD NEWS IS KEPT
================================================================================================
DOT compliance: hard verdict DEAD ON ARITHMETIC (price $150, 3 hrs)
  best possible answers -> price $188, 3.00 hrs
    arithmetic on moved bands: REACHABLE
    after combine(hard, model): DEAD ON ARITHMETIC
  worst answers -> after combine: DEAD ON ARITHMETIC

Every answer set that improves the arithmetic is thrown away by the
floor.  Every answer set that worsens it is kept.  So the 'model may
move an input band' layer is a one-way ratchet toward DEAD: it cannot
change the ranking of a reachable venture upward, and it can only add
false negatives.  It is a veto with no information in it.
