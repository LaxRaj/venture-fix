Venture stress test

What the venture requires, and where the verdict flips.

No revenue forecast. Arithmetic first, model second. The model may move an input band; it cannot produce a verdict.

We compute what each pre-revenue venture requires, check it against a physical limit, and print the exact input value at which the verdict flips. Every number below is an input, a requirement, or a break-even — not a forecast.

The safety property

Hard checks fail closed and set a floor. The model fails open and may only raise severity above it. 

combine("DEAD ON ARITHMETIC", "REACHABLE")   == "DEAD ON ARITHMETIC"   # model cannot revive
combine("REACHABLE", "BURNS THE MARKET")     == "BURNS THE MARKET"     # model can raise
combine("REACHABLE", "garbage-from-timeout") == "REACHABLE"            # fails open
